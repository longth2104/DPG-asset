# ASSET MANAGEMENT 

" I want to create an interactive web app that helps my company efficiently and productively 
manage our asset"

## User stories

1.  I want to keep track off my company asset. To be more specific, given an example of a company assigned laptop, I want to know who is using it, who used to use it, has it ever been broken down or fixed, ...
2. Each asset need to be accompanied with its basic information ( name, series number, specific company id ) along with its legal paper ( reciept, contract,... ). Additionally, a log of the asset should also be accesible conviniently ( when was it bought, which unit has been in possession of it,...)
3. The app should follow the company guideline for asset management. I want to be able to assign and retrieve asset using the app. 
4. I want to be able to make request for asset acquirement, maintainance and liquidation on the app
