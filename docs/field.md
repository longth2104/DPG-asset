# Dynamic field

- Since the asset list is going to be constantly updated, I want the field info to be dynamic:

1. When importing an excel, it don't need to have all the existing field. On the other hand, if the excel file has additional field it is still acceptable

2. While editing and addding asset manually , the user can have the option to add field.

- My corp is operating on holding hierarchy, so a compulsory field is 'company' to show which company an asset is belong to. ( the heirachy is already set)

- When importing an excel , (if the excel file don't have the company field), the user will be prompt to input the company via a drop down menu. ( the list of company are already on the site). There will also be a default option which will set the asset to the company of the user who is importing the asset.

( for the asset that are already imported , treat them as default).
